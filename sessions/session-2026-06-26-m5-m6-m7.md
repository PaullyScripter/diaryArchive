### Content Warnings System
- 4 warning types: adult (age-gated), violence, self-harm, substance
- Writer selects warnings in form
- Reader sees interstitial overlay before content
- Age gate checkbox for adult content
- Acknowledgment stored in sessionStorage per diary
- Owner bypasses overlay on own diaries
- No emojis in warning badges

### UI Decisions
- Diary listings use list-style (border-bottom + left accent) not card grid
- Homepage sections: Latest, Random, Browse by Tags (25 random), Browse by Emotion (25 random)
- Privacy selector uses radio buttons (not toggle buttons)
- Privacy cannot change between public↔private (must delete and recreate)

### Dark Mode Fixes
- Emotion badge uses hardcoded `dark:text-[hsl(15,55%,72%)]` instead of CSS variable
- Code blocks use `text-foreground` for readability
- Tab component uses `bg-tag-bg` instead of `bg-muted`

### Security Fixes
- Rate limiting on profile update (30/min) and email update (5/min)
- All mutations require Bearer token
- Diary queries exclude private/draft at DB level
- Bleach sanitizer strips scripts, event handlers
- CSS sanitizer allows safe properties (font-family, font-size, color, etc.)
- `<style>` tag allowed through sanitizer

### Features Added
- Bold, Italic, Underline, Strikethrough
- Headings H1, H2, H3
- Blockquote, Code Block, Bullet List, Ordered List, Check List
- Font family dropdown (9 fonts)
- Font size dropdown (12 sizes, 10px–48px)
- Source code toggle (`</>` button) — raw HTML editing
- Custom CSS field with available variables reference
- Markdown shortcuts (`#`, `**`, `>`, `-`, etc.)
- Keyboard shortcuts (Ctrl+B, Ctrl+I, Ctrl+S, etc.)
- Undo/Redo

- Unsaved changes warning (beforeunload)
- Preview button (eye icon) — full-screen preview modal before publish
- Tags autocomplete with debounced API search
- Dynamic import (ssr: false) to avoid hydration mismatch
